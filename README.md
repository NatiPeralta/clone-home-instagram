# 📸 Clone da Landing Page do Instagram

Projeto de recriação da interface de login do **Instagram**, focado na construção de layout fiel, responsividade e práticas de estilização moderna com HTML5 e CSS3.

O projeto foi desenvolvido como prática durante as aulas do curso **Formação Front-end** ministrado pela escola **Hora de Codar** na Udemy.

---

## 🚀 Destaques do Projeto

- 🎨 **Fidelidade Visual:** Reprodução da interface original da tela de login do Instagram desktop e mobile.
- 📐 **Layout Responsivo:** Adaptação fluida do formulário e elementos visuais conforme a largura da tela.
- 📱 **Carrossel de Imagens do Smartphone:** Layout com área de exibição das telas do aplicativo.
- 🧱 **Boas Práticas de CSS:** Uso de **Flexbox**, estilização modular e resets CSS para consistência entre navegadores.

---

## 🛠️ Tecnologias Utilizadas

- **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Estruturação semântica da página.
- **[CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS):** Estilização, Flexbox, posicionamento avançado e media queries para responsividade.
- **[Git & GitHub](https://github.com/):** Versionamento do código.
